# Blitz Search

![Blitz Search In motion](https://blitzsearch.s3.us-east-2.amazonaws.com/VS_Hero30fps.gif)

Blitz Search is an external application, this Visual Studio Extension exists to provide a couple of commands with aims of being a replacement, OR compliment (your choice) to the built in find-and-replace.  

* <b>Search This</b> (Selection) - Places the selection in the Blitz Search Search Box
* <b>Search This</b> (Caret on a word) - Places word that the caret is on as a <b>Whole-Word</b> Search in the Blitz Search Search box.
* <b>Replace This</b> - Works the same as Search This, only it will open up Replacement components.

In addition, this Extensions provides Solution->Project, and Active Files, context to Blitz Search so that You can scope your search to those things.

## What is Blitz Search?

Blitz Search is a %100 Free, Open sourced, stand-alone file contents search tool, with an aim to provide an improved Find-in-files experience for multiple IDE's / Code Editors.

For more information and Download, visit:
 - [Natestah.com](https://natestah.com)

Source Code:
 - https://github.com/natestah/blitzSearch/

## Requirements
> Currently Windows x64 only, Download and install the FREE Companion application Blitz Search. If you don't have Blitz Search Installed, the extension will point you to the downloads page.
